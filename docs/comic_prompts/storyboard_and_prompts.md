## Style Notes for Image Generation

- **Typography**: Clean sans-serif for captions, slightly rounded for narrator boxes. Bilingual: Chinese primary, English secondary in smaller size or lighter weight.
- **Panel composition**: White gutters create "breathing room." Each panel should be readable at thumbnail size.
